# TeamPulse

TeamPulse is a team collaboration platform for managing team updates,
tasks, discussions, and progress in one place.

## Problem

Teams often use multiple tools for updates, tasks, and discussions.
TeamPulse aims to bring these workflows into one simple platform.

## Core Features

- User authentication
- Team management
- Team feed
- Posts
- Comments
- Reactions
- Task management
- Task assignment
- Task progress
- Team dashboard
- Weekly summary

## Planned Tech Stack

- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL
- Testing: To be decided during development
- CI/CD: GitHub Actions
- Deployment: To be decided
