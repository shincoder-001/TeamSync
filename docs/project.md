# TeamPulse Project

## Purpose

TeamPulse is a team collaboration platform for sharing updates,
managing tasks, and tracking team progress.

## Initial MVP

- Authentication
- Team management
- Team feed
- Comments
- Reactions
- Task management
- Team dashboard

## Development Workflow

1. Create GitHub Issue
2. Create feature branch
3. Implement feature
4. Test feature
5. Commit changes
6. Push branch
7. Create Pull Request
8. Code review
9. Merge
10. Delete branch
